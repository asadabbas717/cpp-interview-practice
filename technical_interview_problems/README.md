# Technical Interview Problem Set

Each numbered file is a standalone C++17 solution.  The number is only an
index; problems are grouped broadly by technique rather than difficulty.

| # | Problem | Main technique | Time |
|---|---|---|---|
| 01 | Two Sum | hash map | O(n) |
| 02 | Longest substring without repeats | sliding window | O(n) |
| 03 | Product except self | prefix/suffix products | O(n) |
| 04 | Trapping rain water | two pointers | O(n) |
| 05 | Maximum subarray | Kadane's algorithm | O(n) |
| 06 | Merge intervals | sorting | O(n log n) |
| 07 | Search rotated array | binary search | O(log n) |
| 08 | Kth largest element | min heap | O(n log k) |
| 09 | LRU cache | hash map + list | O(1) average |
| 10 | Valid parentheses | stack | O(n) |
| 11 | Minimum window substring | sliding window | O(n) |
| 12 | Reverse linked list | pointer rewiring | O(n) |
| 13 | Linked-list cycle | Floyd's algorithm | O(n) |
| 14 | Merge k sorted lists | min heap | O(n log k) |
| 15 | Binary-tree level order | BFS | O(n) |
| 16 | Lowest common ancestor | tree recursion | O(n) |
| 17 | Number of islands | DFS | O(rows * cols) |
| 18 | Course schedule | topological sort | O(V + E) |
| 19 | Word break | dynamic programming | O(n²) |
| 20 | Coin change | dynamic programming | O(amount * coins) |
| 21 | Longest increasing subsequence | binary-search DP | O(n log n) |
| 22 | Edit distance | 2D dynamic programming | O(mn) |
| 23 | House robber | state DP | O(n) |
| 24 | Single number | XOR | O(n) |
| 25 | Reverse bits | bit manipulation | O(1) |

Use these as interview practice: first explain the brute-force route, then
identify the constraint that requires the technique shown above.
